Random Variables & the Binomial Distribution

Discrete probability distributions, expected value and standard deviation, transforming and combining random variables, and the conditions, formula, mean and standard deviation of a binomial count — with interpretation in context.

1. Discrete Random Variables and Probability Distributions

A random variable takes numerical values determined by a random phenomenon. A discrete random variable has finitely many (or countable) possible values. Its probability distribution lists every value with its probability; it may be given as a table, a graph or a function, and can be found by the rules of probability or estimated by simulation.

Two Non-Negotiable Conditions
0 ≤ P(xi) ≤ 1 for every value     ∑ P(xi) = 1
A cumulative probability distribution gives P(X ≤ x) for each value; the last entry must be exactly 1. Parameters (such as μX and σX) are fixed numbers describing the distribution — they are not statistics computed from a sample.

2. Expected Value, Variance and Standard Deviation

Mean and Standard Deviation of a Discrete Random Variable
μX = E(X) = ∑ xi P(xi)
σ2X = Var(X) = ∑ (xi − μX)2 P(xi)
σX = SD(X) = √Var(X)
Interpretation (required on FRQs): μX is the long-run average value of X over many repetitions, in context; σX is the typical distance of X from that mean in the long run. For the table above, μX = 0(.10) + 1(.25) + 2(.40) + 3(.25) = 1.80.

3. Linear Transformations and Combining Random Variables

Transforming X, and Adding or Subtracting Independent Variables
μaX+b = aμX + b     σaX+b = |a| σX
μX±Y = μX ± μY
σ2X±Y = σ2X + σ2Y  (X, Y independent)
Adding a constant shifts the centre but not the spread; multiplying by a negative constant flips the centre and scales the spread by its absolute value. For a difference of independent variables the variances still add — never subtract them. Standard deviations are combined by √(σ2X + σ2Y), never by σX + σY.

4. The Binomial Distribution: Conditions, Probability, Mean and SD

BINS — Justify Before You Compute
P(X = k) = (n choose k) pk (1 − p)n−k
μX = np     σX = √(np(1 − p))
Binary: each trial has only success / failure. Independent trials: when sampling without replacement, check the 10% condition n ≤ 0.10N. Number of trials n is fixed in advance. Same probability of success p on every trial. X counts the number of successes, so k = 0, 1, …, n.
(n choose k) = n! / (k! (n − k)!).
Worked example and calculator commands

For X ~ Bin(10, 0.30): μX = 3 successes and σX = √(10 · .3 · .7) ≈ 1.45. "Over many sets of 10 trials, we expect about 3 successes, typically varying by about 1.45 from that mean."   binomPdf(10,.3,4) gives P(X = 4); binomCdf(10,.3,4) gives P(X ≤ 4); randBin(10,.3,500) simulates 500 such counts.

5. Exam Traps

Traps the exam actually tests
  • State the BINS conditions in context before using the formula; "independent" needs the 10% condition when sampling without replacement.
  • binomPdf vs binomCdf: exactly k needs Pdf; "at most k" needs Cdf; "at least k" is 1 − binomCdf(n, p, k − 1).
  • Variance is not additive in SD: add variances, then take the square root.
  • A difference subtracts means but ADDS variances for independent variables.
  • Interpret μ and σ in context with "long run" / "typical", not "the most likely value".
  • P(X = x) = 0 for continuous variables — only intervals have probability (see the Normal distribution sheet).

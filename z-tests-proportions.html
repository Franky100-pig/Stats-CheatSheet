Topic 03 · Hypothesis Tests & z-Tests

Hypothesis Testing & z-Tests (Proportions & Known-σ Means)

Null vs. alternative hypotheses, test statistic formulas, pooled proportion pc, p-value rules, Type I / II errors, and statistical power.

1. Core Testing Framework & Variable Definitions

Symbol Name Definition & Mathematical Role
H0, Ha Null & Alternative Hypotheses H0 = claim of "no effect / no difference" (always uses =, e.g., p = p0).
Ha = research claim (<, >, or ≠). Always written using parameters (p, μ), never p or x!
p0, μ0 Null Value Specific hypothesized population parameter value assumed to be true under H0.
z Standardized Test Statistic z = (Statistic − Null Parameter) / (Null Standard Deviation). Measures how many SDs the sample result lies from H0.
p-value Observed Significance Probability of getting a statistic as extreme as (or more extreme than) our observed data, assuming H0 is true.
α Significance Level Decision threshold (commonly 0.05 or 0.01). Equals P(Type I Error) when H0 is true.
β Type II Error Rate Probability of failing to reject H0 when Ha is actually true.
1 − β Statistical Power Probability that a test correctly rejects a false H0 at a specific true alternative value.

2. All z-Test Formulas

1-Proportion z-Test (Testing H0: p = p0)
z = p − p0 √p0(1 − p0)n
Variables: p = X/n (sample proportion); p0 (null value); n (sample size).
Important: Denominator and Large Counts condition (np0 ≥ 10, n(1−p0) ≥ 10) BOTH use p0 (not p!), because we assume H0 is true.
2-Proportion z-Test (Testing H0: p1 − p2 = 0)
z = (p1 − p2) − 0 √ pc(1 − pc) (1n1 + 1n2)     where     pc = X1 + X2 n1 + n2
Variables: X1, X2 = success counts in each sample; n1, n2 = sample sizes; pc = pooled (combined) sample proportion under H0: p1 = p2.
Large Counts Check: Verify n1pc, n1(1−pc), n2pc, n2(1−pc) ≥ 10.
1-Sample z-Test for a Mean (Only when Population SD σ is Known)
z = x − μ0 σ / √n
Variables: x = sample mean; μ0 = null mean; σ = known population SD; n = sample size. (If σ is unknown and you use sample s, you MUST use a t-test!)

3. Computing the p-Value & Making a Decision

Alternative Hypothesis (Ha) Tail Type p-Value Formula (Z ~ N(0, 1))
Ha: param > null Right-tailed P(Z ≥ zobs) = normalcdf(z, ∞, 0, 1)
Ha: param < null Left-tailed P(Z ≤ zobs) = normalcdf(-∞, z, 0, 1)
Ha: param ≠ null Two-tailed 2 · P(Z ≥ |zobs|) = 2 · normalcdf(|z|, ∞, 0, 1)
Conclusion Rule & Template
  • If p-value ≤ α: "Because the p-value ([val]) ≤ α ([val]), we reject H0. There is convincing statistical evidence that [Ha in context]."
  • If p-value > α: "Because the p-value ([val]) > α ([val]), we fail to reject H0. We do not have convincing evidence that [Ha in context]." (Never say "accept H0" or "prove H0 is true"!)

How to Increase Statistical Power (1 − β)

1. Increase sample size n (shrinks SE, lowers both β and overlap without raising α).  |  2. Increase α (e.g., 0.01 → 0.05; trades off higher Type I risk for lower β).  |  3. Larger true effect size |ptrue − p0|  |  4. Reduce variability σ.

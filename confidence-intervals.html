Unit 06 · Topic 02 · Confidence Intervals

Confidence Intervals (z-Intervals & t-Intervals)

Universal interval structure, critical values (z* vs. t*), standard error formulas, minimum sample size calculations, and exam-safe interpretation templates.

1. Universal Structure & Variable Definitions

General Confidence Interval Formula
Confidence Interval = (Point Estimate) ± (Critical Value) × (Standard Error of Statistic)
CI = PE ± ME = PE ± CV · SE
Width of Interval: Width = Upper − Lower = 2 · ME. Half the width gives the Margin of Error: ME = (Upper − Lower)/2, and midpoint gives PE = (Upper + Lower)/2.
Symbol Name Definition & Notes
PE Point Estimate Best single-value guess of the target parameter (p, x, p1 − p2, or x1 − x2). Always lies at the exact center of the interval.
C, α Confidence Level & Tail Area C = middle area (e.g., 0.90, 0.95, 0.99); α = 1 − C = total area in both tails (α/2 per tail).
z* Normal Critical Value Standard Normal quantile cutting off upper area (1 − C)/2. Common values: 90% → 1.645, 95% → 1.960, 99% → 2.576.
t* Student's t Critical Value Critical value from t(df) distribution; always larger than z* to account for estimating σ with s.
df Degrees of Freedom One-sample / paired t: df = n − 1. Two-sample t: Welch's formula (from tech) or conservative min(n1 − 1, n2 − 1).
ME Margin of Error ME = CV · SE. Measures maximum expected estimation error at confidence level C (does not include bias/nonresponse error).

3. Solving for Minimum Sample Size (n)

To guarantee a Margin of Error at most ME at confidence level C, solve z* · SE ≤ ME for n and always round UP to the next whole integer.

Minimum Sample Size Formulas (Always Round Up!)
For Proportion p:  n ≥ p*(1 − p*) (z*ME)2     |     For Mean μ:  n ≥ (z* · σME)2
Variables: p* = prior guess for p (if no prior estimate is given, use conservative worst-case p* = 0.5 because 0.5(0.5) = 0.25 maximizes variance); σ = known/planning population SD.

4. What Affects Margin of Error & Interpretation Rules

Correct Interpretation Templates

1. Interpreting the Interval:
"We are C% confident that the interval from [Lower] to [Upper] captures the true [population parameter in context]."

2. Interpreting Confidence Level (C%):
"If we took many random samples of the same size n and built a C% CI from each, about C% of those intervals would capture the true [parameter]."

High-Frequency Exam Traps
  • Never say "95% probability" that the true parameter is in a specific calculated interval! Once computed, the parameter is fixed, so it is either in (1) or out (0).
  • Higher C → Wider interval (z* increases). Larger n → Narrower interval (SE shrinks by 1/√n).
  • 2-Prop CI never uses pooled pc! Use individual p1 and p2 (pooled pc is only for 2-Prop z-Tests).
Using a Confidence Interval to Test a Two-Sided Hypothesis

A two-sided C% confidence interval corresponds to a two-sided significance test at α = 1 − C. If the null value (p0, μ0, or 0 for a difference) falls outside the CI, reject H0 at level α; if it falls inside, fail to reject H0.

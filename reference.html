Quick Reference & Tools

The working tools that sit beside the chapters: pick the right inference procedure, check a symbol, review the exam traps and open the TI-Nspire companion. The chapter-by-chapter reading list lives in the table of contents.

How to use these tools

  1. Pick the procedure first — the picker below decides between a z and a t procedure from the data structure and the goal.
  2. Then check the conditions (Random, 10%, Normal / Large Counts) and write them in words; a correct number with no conditions is not a complete free-response answer.
  3. Then run it on the calculator and interpret the output in context. The companion Digital-Nspire-for-Stats uses the TI-Nspire's own command names, so the syntax here is the syntax on the handheld.

Exam traps worth memorising

  1. Parameters, not statistics: hypotheses and interval interpretations are about p, μ, μd, p1 − p2 — never p or x.
  2. Variances always add for independent samples, even when the means are subtracted.
  3. Pooled pc belongs to the 2-Prop z-test only, never the interval.
  4. Large Counts changes with the null: a 1-Prop test checks n p0 ≥ 10, an interval checks np ≥ 10.
  5. Round n up when solving for sample size, so the margin of error stays inside budget.
